# Vue Todo List

這是我的第一個 Vue 練習作品，使用 Vue 3 CDN 製作。

## 功能

- 新增待辦事項
- 按 Enter 新增
- 刪除待辦事項
- 編輯待辦文字
- 勾選完成 / 未完成
- 篩選全部 / 未完成 / 已完成
- 顯示未完成數量
- 清除已完成
- 使用 localStorage 儲存資料

## 使用技術

- HTML
- CSS
- JavaScript
- Vue 3 CDN

## 學習重點

- createApp
- data
- methods
- computed
- watch

- v-model
- v-for

- :class
- @click
